Problem: A student has marks for five subjects. Write a C program to read the marks of all five subjects and calculate the total marks, average marks, and percentage. Display all the three results clearly.

Algorithm:
1. Start.
2. Read the marks of the five subjects using scanf function.
3. Calculate the total marks of all five subjects.
4. Calculate the average mark of the marks of the five subjects.
5. Calculate the percentage of the total marks.
6. Display the thus calculates total, average, and percentage using the printf function.
7. stop.
