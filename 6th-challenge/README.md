Algorithm:
1.	Start
2.	Ask the user how many readings must be taken
3.	Take the individual readings from the user
4.	Calculate sum of all the elements in the array and also find the average of the elements
5.	Print the maximum element, minimum element and the sum and average of the elements in the array
6.	Find and print the second largest reading
7.	Find and print the number of local peaks
8.	Find and print the length of the longest contiguous run
9.	Shift the elements of the array by k places and print the shifted/rotated array
10.	Ask for the last 2 digits of the user’s registration number and calculate d = (r % 9) +1 (r is the last two digits of the registration number) then check how many elements of the array are divisible by d and print d and the count of numbers divisible by d
11.	Stop
