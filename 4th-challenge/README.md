Algorithm:
1. Declare small, medium, large and total counts and small, medium, large totals and total expense to zero
2. Read expense
3. If expense = 0 then stop
4. If expense is negative value then read again
5. If expense is positive then add expense to total expense and increase total count by 1
6. Increase the respective count by 1 and add the expense to the respective total as well
7. If total count is greater than 1 then print number of valid expenses, total of valid expenses, small expenses details, medium expenses details, large expense details and average valid expense
8. Else print no valid expenses were entered
